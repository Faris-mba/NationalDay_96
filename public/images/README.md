# مجلد الصور

ضع هنا صور جولة **🖼️ خمّن الصورة**. الأسماء التالية مطلوبة كما هي
(كما وردت في `data/questions.json`):

| الملف | الإجابة الصحيحة |
|---|---|
| `kingdom-tower.jpg` | برج المملكة – الرياض |
| `hegra.jpg` | قصر البنت – الحِجر (مدائن صالح) |
| `masmak.jpg` | قصر المصمك – الرياض |
| `king-fahd-fountain.jpg` | نافورة الملك فهد – جدة |
| `maraya-alula.jpg` | مبنى مرايا – العُلا |
| `dhee-ayn.jpg` | قرية ذي عين – الباحة |
| `al-balad.jpg` | جدة التاريخية (البلد) |
| `kabsa.jpg` | كبسة |

**قبل أن تضيف صورك**، تعرض اللعبة صورة خضراء مؤقتة مكتوب عليها اسم الإجابة،
فتقدر تجرّب الجولة كاملة من الآن.

## نصائح
- مقاس مناسب: عرض 1600px تقريبًا، بنسبة 3:2.
- اختر صورًا فيها تفصيلة مميزة قرب المنتصف، لأن الجولة تبدأ بتقريب شديد على الوسط.
- تقدر تغيّر أسماء الملفات أو تضيف أسئلة صور جديدة من `/host/settings` ← بنك الأسئلة،
  بحقل مسار الصورة (مثال: `/images/صورتي.jpg`).
